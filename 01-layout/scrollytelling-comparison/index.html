mature comparison component + scroll narrative
01 / Baseline

Show The Existing State First.

Start almost entirely on the “before” side. The reader needs a stable baseline before any improvement is introduced.

02 / Compare

Put Both States In The Same Frame.

The divider moves to the center. Because both images share one coordinate system, differences become much easier to inspect.

03 / Result

Let The New State Take Over.

The “after” view becomes dominant. Scroll progression now communicates a directional change rather than merely offering a draggable widget.

04 / Takeaway

Finish On The Difference That Matters.

Return to a partial comparison and add one explicit annotation. The end state answers why the change is meaningful.
