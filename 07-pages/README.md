# 07-pages — 完整页面复刻

**仓库的核心目录。** 所有归档资产的来源：先在这里 1:1 复刻完整作品，理解之后再把高复用部分拆到 01~06。

## 存放什么

- 对某个优秀作品的完整页面复刻（信息可视化作品、获奖网站、创意交互页面）
- 自己的完整实验页面
- 每个页面一个独立子目录，自包含、可独立运行

## 什么值得归档

只要是"完整跑通、看过实现、从中学到东西"的页面就值得放进来。哪怕最后没有拆出任何可复用资产，页面本身就是学习记录。

## 命名方式

`来源或作者-作品名`，kebab-case，例如：

- `pudding-wealth-shown-to-scale/`
- `reuters-climate-spiral/`
- `own-experiment-data-rain/`

## 子目录建议包含

```
07-pages/xxxx/
├── README.md      # 原始出处（链接/截图）、复刻目标、学到的技术点、
│                  # 哪些部分已拆出归档（链接到 01~06 对应目录）
├── index.html     # 页面入口
├── src/           # 页面代码
├── data/          # 页面用数据（控制在可提交大小内）
└── reference/     # 可选：原作的截图、录屏（注意版权，仅个人学习用）
```

## 规则

- 页面允许"脏"：先求复刻到位，重构是拆分时的事。
- 每个页面 README 必须写清楚：**原作出处** 和 **学到了什么**。
- 拆出资产时在页面 README 里记录拆分去向，在资产 README 里记录来源页面。
