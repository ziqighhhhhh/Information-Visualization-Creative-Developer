# 收集标准（batch 1 复盘结论）

从 101 件候选、44 件保留的审查记录中提炼的口味过滤器。后续收集按此选品。

## 收（高命中率信号）

- **交互优先**：hover / drag / cursor 驱动 / 可操作的（magical hover、attract、image track、拉绳）
- **文字即材料**：scramble、neon、裂纹、反色、字母坠落、数字雨、text-to-particles
- **可迁移的技巧**：Houdini @property、oklch、sibling combinator、clip-path、mask、radio hack——"看完能偷走一招"
- **有名字的滚动技法**：假横向滚动、Observer 连续章节、continuous snap 循环（拒绝通用 ScrollTrigger demo）
- **品牌相关件**：logo 动画、loader、按钮组、开关

## 不收（高删除率信号）

- 纯氛围循环：烟花、雪花、轨道粒子、parallax 场景——美但被动
- 重型 3D 场景：整个场景才成立、参数拆不走的（Perlin 雕塑、skybox）
- 纯 CSS 摆件/游戏：牛顿摆、棋、记忆游戏（除非机制本身是考点）
- 工具型 demo：theme switcher、API 示例、模板、knob 控件
- 框架绑定：React/Vue 专用 demo（库里不引框架）
