# references — 参考与调研资料

外部参考材料：灵感、教程、技术调研。这里只放**资料**，不放实现代码。

## 存放什么

- 灵感收集：优秀作品链接、截图、录屏的归档
- 教程与学习笔记（Markdown 记录）
- 技术调研：某类效果的实现方案对比、选型笔记
- 配色板、字体搭配、设计规范摘录

## 什么值得归档

- 以后还会回来查的链接和笔记
- 调研过、形成过结论的技术对比

不值得归档：浏览器书签式的"先存着"链接（没有一句话说明的链接等于没存）。

## 组织方式

按主题建子目录或单文件，kebab-case，例如：

```
references/
├── inspiration/         # 灵感收集，每个作品一个 md（含链接 + 截图 + 一句话点评）
├── tutorials/           # 教程笔记
└── research/            # 技术调研文档，如 webgl-vs-canvas-particles.md
```

## 规则

- 每条资料附一句话：**它好在哪里 / 我为什么存它**。
- 涉及他人作品的截图录屏仅作个人学习参考，不进任何对外产物。
