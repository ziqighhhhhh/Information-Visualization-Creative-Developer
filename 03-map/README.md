# 03-map — 地图

地理 / 空间数据可视化相关资产。

## 存放什么

- 底图方案（矢量瓦片样式、暗色底图配置）
- 投影选择与转换（GeoJSON → 屏幕坐标）
- 地图上的数据表达：点聚合、热力、流向、等值线
- 地图交互：缩放、悬停高亮、区域联动
- 地图装饰：指北针、比例尺、图例

## 什么值得归档

- 能直接套用的地图样式（一套底图配色 + 图层配置）
- 经过验证的数据处理流程（坐标系、简化、裁剪）
- 交互联动模式的完整例子

不值得归档：某个项目专用的、与特定数据集强绑定的地图代码。

## 命名方式

目录名只写稳定能力（地图类型），配色、动效等可变表现写进代码和资产 README，不写进目录名。

`地图类型`，kebab-case，例如：

- `world-map/`
- `basemap/`
- `choropleth/`
- `flow-map/`

反例：`dark-world-map-glow`（dark、glow 都是可变表现）。

## 子目录建议包含

```
03-map/xxxx/
├── README.md      # 数据要求、样式配置说明、依赖的库及版本
├── index.html     # 最小演示
├── data/          # 小型示例数据（GeoJSON 等，控制在可提交大小内）
└── src/           # 实现代码
```
